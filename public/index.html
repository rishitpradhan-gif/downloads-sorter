Using Downloads Sorter

  1. Choose the folder you want to organize.
  2. Select Preview sorting. Review each destination.
  3. Select Sort these files to move the listed files.
  4. Use History to undo a run.

Automatic sorting handles new files only while the app is running. Rules can be edited; saving rules stops automatic mode so you can review the change.

Sorting keeps file contents and avoids overwriting existing names. Other apps can still change files, so close editors and downloads before organizing. Keep a backup of important work.

Undo records live inside the selected folder, in .downloads-sorter. Keep that folder if you want to undo.

To stop the app, close its launcher window or press Ctrl+C there. Closing this browser tab alone does not stop the local server.
